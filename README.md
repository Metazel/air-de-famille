# Air de famille

Application web installable (Android, ordinateur) qui compare des visages trait par trait,
retrouve qui ressemble à qui dans une famille à âge égal, et propose des simulations
(vieillir, rajeunir, fusionner deux visages).

**Confidentialité** : toute l'analyse se fait sur l'appareil. Aucune photo n'est envoyée ni
stockée sur ce site ; une politique de sécurité (CSP) interdit toute connexion vers un autre site.
Ce dépôt ne contient que le code de l'application.

Ouvrir l'application : `https://<identifiant>.github.io/air-de-famille/`

Ce n'est pas un test de parenté.
